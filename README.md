DAF — Delayed Auditory Feedback
Приложение для замедления речи в реальном времени на Windows 10/11.
Говоришь в микрофон — в наушниках слышишь свой голос с задержкой. Мозг непроизвольно подстраивается и начинает замедлять темп речи.

Ползунки подробнее
Задержка (мс)
Ключевой параметр. Чем больше — тем сильнее эффект замедления речи. Рекомендуемый диапазон — 150–250 мс.
Громкость DAF
Насколько громко слышен задержанный голос в наушниках. 100% — нормальная громкость, 200% — усиленная.
Микс live → DAF

0% — только живой голос, DAF-эффекта нет
50% — слышен и живой, и задержанный одновременно
100% — только задержанный голос (классический DAF-режим)

Для максимального эффекта: микс 100%, задержка 200 мс.

Важно

Используй проводные наушники — Bluetooth добавляет свою задержку
Отключи улучшение звука в настройках Windows — эхо-отмена подавляет задержанный сигнал
Не запускай от имени администратора
